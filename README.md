# Consumo MK House

Tablero de consumo eléctrico de la casa contra la producción de los paneles solares.

- `index.html` — la página (se genera con `scripts/build.py` a partir del tablero fuente).
- `data.json` — los datos que lee la página. Se actualiza cada mañana con el día anterior completo.

Los datos públicos no incluyen nombre del titular, dirección, números de servicio o cuenta de CFE ni números de serie de los equipos.
